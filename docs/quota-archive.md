# 额度基准长期归档（基于主线 v0.3.2 的独立增强）

## 范围

保留主线官方图表、布局、刷新策略、模型 Token 明细、估值和普通快照生命周期。没有引回旧维护版的独立页面按钮、窗口替换、周期推测、人工重置记录和刷新失败降级策略。主线 manifest 版本仍为 0.3.2，不发布商店版本。

扩展弹窗新增“记录当前基准”和“本地历史与导出”。归档服务不挂到主线报告刷新或被动刷新路径；只有明确点击记录才增加请求。

## 使用与数据口径

1. 在 ChatGPT 分析页用主线刷新取得报告。
2. 五分钟内，在工具栏弹窗点击“记录当前基准”。额外发起两个只读同源请求：usage（确认账号）、daily-token-usage-breakdown（百分比）。同页面并发记录合并，不自动重试。
3. 历史页从扩展来源 IndexedDB 读取记录，可按账号筛选、导出全部归档 JSON。历史页不发官方请求；只导入本地旧快照中已有 percentageData 的报告，不为普通主线快照伪造基准。

归档记录时查询的百分比与最近报告中的 Credits 配对，并保留 sourceCapturedAt，二者可能有统计延迟。账号未知/切换、报告过期、错误单位或接口失败均不写入新采集记录。

反算值 = 日 Credits ×100 / 日历史分析百分比。每份记录保留日期/Credits/百分比/反算值，并给出中位数、最小最大值、有效天数。它仅是当次接口隐含的换算口径，不代表真实或历史套餐周容量，不加入假设模型倍率。日百分比为零、缺失、非数字、负数或未来占位日期不产生有效基准。

## 存储与兼容

复用旧维护版 IndexedDB `codex-meter-quota-archive` v1、`snapshots` store 与账号+采集时间 key；已有记录不覆盖、不自动淘汰，旧维护版归档可直接读取。清空主线普通快照不会删除归档。未知账号的旧快照归入 unknown，不尝试跨账号推断。

无新增权限，无上传、遥测或凭证保存。归档位于扩展来源，通过 service worker 写入，不写入 chatgpt.com 来源。数据仍受浏览器容量/磁盘限制；失败明确显示，不删历史。卸载、清除扩展数据、换配置文件会丢失，请定期导出。导出含账号作用域与用量明细；分享前脱敏。当前未提供 JSON 导入 UI。
